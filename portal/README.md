# CM 포털 사용법

건설사업관리(CM) 서비스를 소개하는 안내용 웹 페이지임. 별도 설치나 인터넷 연결 없이 `index.html`을 열면 바로 사용할 수 있음.

## 1. 실행 방법

1. 폴더의 `index.html`을 더블클릭하여 웹 브라우저(크롬, 엣지 등)에서 엶.
2. 상단 메뉴를 눌러 원하는 섹션으로 이동함. 스크롤하면 현재 위치의 메뉴가 강조됨.
3. 화면이 좁은 모바일에서는 오른쪽 위 햄버거(≡) 버튼을 눌러 메뉴를 펼침.

## 2. 폴더 구성

```
.
├── index.html                      포털 본 화면 (이전 이름: cm-portal_v2.html)
├── README.md                       이 문서
├── files/
│   ├── cm-service-introduction.pdf          (이전 이름: CM_서비스소개서.pdf)
│   └── process-quality-safety-standards.pdf (이전 이름: 공정품질안전_관리기준.pdf)
├── 이전버전/                       변경 전 사본과 이전 시안 보관
│   ├── cm-portal-v2.html           index.html 최초 변경 전 원본 사본
│   ├── index-before-xai.html       xAI 스타일 적용 전 index.html
│   └── cm-portal-v1·v3, cm-portal-v2-*.html   이전 시안들
```

- 파일명은 영문 소문자와 하이픈만 사용함. (폴더 `이전버전`과 `README.md`는 요청한 이름 그대로 둠.)
- `files/` 폴더의 PDF는 포털 자료실의 "PDF 자료" 목록에 연결되어 있음. 새 PDF를 추가하려면 `files/` 폴더에 넣고 `index.html`의 목록(`class="flist"`)에 항목을 한 줄 추가해야 함.

## 3. 화면별 사용법

| 섹션 | 하는 일 | 사용법 |
|---|---|---|
| 홈 | 포털 소개 | "업무 흐름 보기", "공정 계산기 사용" 버튼을 누르면 해당 섹션으로 이동함 |
| 서비스 | CM 서비스 5개 영역 소개 | 기획·설계·발주·시공·사후관리 카드로 주요 업무를 확인함 |
| 업무 흐름 | 5단계별 주요 업무 | 1~5번 단계 버튼을 누르면 아래 상세 내용이 바뀜 |
| CM 방식 | CM for Fee와 CM at Risk 비교 | 두 방식의 역할·책임 범위 차이를 나란히 읽음 |
| 관리 항목 | 공정·품질·안전·원가 관리 항목 | 항목별 점검 내용을 확인함 |
| 공정 계산기 | 계획·실적 공정률 비교 연습, 간단 계산기 | 아래 4번 참고 |
| FAQ | 자주 묻는 질문 10개 | 아래 5번 참고 |
| 자료실 | 샘플 문서 2종과 PDF 2종 다운로드 | 아래 6번 참고 |

## 4. 공정 계산기

1. "계획 공정률(%)"과 "실적 공정률(%)"에 0~100 사이의 숫자를 입력함. 소수점 첫째 자리까지 입력할 수 있음.
2. 두 값을 모두 입력하면 막대 그래프, 차이(실적 − 계획, %p), 판정 결과가 바로 표시됨.
3. 판정 기준은 다음과 같음.
   - 정상: 차이가 −3.0%p 이상(계획 이상 포함)
   - 주의: 차이가 −3.0%p 미만 ~ −10.0%p 이상
   - 지연: 차이가 −10.0%p 미만
4. 0~100을 벗어나거나 숫자가 아닌 값을 입력하면 "입력 오류"와 안내 문구가 표시됨.
5. "초기화" 버튼을 누르면 입력값이 지워지고 첫 입력 칸으로 돌아감.
6. 판정 기준은 예시임. 실제 현장은 계약·발주처 기준을 따라야 함.

### 간단 계산기 (공정 계산기 아래)

1. "계산식" 칸에 식을 입력하거나 키패드를 누르면 결과가 바로 표시됨. 예: `(1,250,000 + 350,000) × 0.4` → `640,000`
2. 사용 기호: `+ − × ÷ ( ) % .` 및 천 단위 쉼표. `*`, `/` 입력도 가능하며 Enter는 `=`와 같음.
3. 0으로 나누기, 괄호 오류, 허용되지 않는 문자는 안내 문구가 표시됨.
4. 소수는 최대 10자리까지 표시하며, 원 단위 절사·반올림은 하지 않음.
5. 입력 내용은 저장하지 않고 외부로 전송하지 않음(브라우저 저장소·네트워크 미사용).

## 5. FAQ 검색

- 검색창에 단어를 입력하면 질문과 답변에서 해당 단어를 찾아 강조하고, 일치하는 항목의 답변을 자동으로 펼침. 예: 수수료, 안전, 공기
- 검색창 아래 분류 버튼(전체, 기본, 방식·계약, 공정·품질, 안전·원가)으로 항목을 좁힐 수 있음. 검색어와 분류는 함께 적용됨.
- 일치하는 항목이 없으면 안내 문구가 표시됨. 검색어를 지우면 전체 목록으로 돌아감.

## 6. 자료실

- "요약본 다운로드", "가이드 다운로드" 버튼을 누르면 샘플 문서가 텍스트(.txt) 파일로 바로 만들어져 내려받아짐.
- 내려받는 파일명은 `CM_서비스_요약본.txt`, `CM_업무_가이드.txt`임.
- 외부 공개 전에 PDF 본문의 발행처·공개구분 표기와 문구를 확인해야 함(점검 결과 반영 전 상태이면 PDF는 올리지 않음).
- 그 아래 "PDF 자료" 목록에는 `files/` 폴더의 PDF가 파일명·설명·용량과 함께 표시됨.
  - "다운로드" 버튼을 누르면 새 창이 열리지 않고 바로 내려받아지며, 저장되는 파일명은 한글임.
  - `CM_서비스소개서.pdf` (235.3KB), `공정품질안전_관리기준.pdf` (204.9KB)
  - 두 PDF는 본문에 "교육용 샘플 자료"로 표시된 가상 문서이므로 실제 업무에는 사용하지 않아야 함.

## 7. 알아둘 점

- 화면 오른쪽 위 해·달 버튼으로 다크/라이트 모드를 바꿀 수 있으며, 선택한 모드만 브라우저에 기억됨(계산 입력은 기억하지 않음).
- 아래로 스크롤하면 오른쪽 아래에 "맨 위로" 버튼이 나타남.
- 본 페이지는 안내용 샘플이며 법적 효력이 없음.
- `index.html`을 수정할 때는 먼저 사본을 만들어 두기 바람. 변경 전 모습은 `이전버전/cm-portal-v2.html`(최초 원본)과 `이전버전/index-before-xai.html`(xAI 스타일 적용 전)에 보관되어 있음.
- 현재 화면은 xAI 스타일(기본 다크, 라이트 전환 가능)임. 계산기 추가 전 모습은 `이전버전/index-before-calc.html`에 보관됨. 이전 밝은 화면이 필요하면 위 사본을 `index.html`로 복사해 사용함.
